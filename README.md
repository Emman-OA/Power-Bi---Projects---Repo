📊 Power BI Retail & Sales Analytics Dashboard | Data Technician Bootcamp
🚀 Project Overview
This project was completed as part of a Data Technician Bootcamp and focused on transforming raw retail and sales data into meaningful business insights using Microsoft Power BI.

The project involved data preparation, transformation, modeling, and visualization to create interactive dashboards that enable stakeholders to explore sales performance, customer trends, product insights, and regional performance. Using Power BI's powerful analytics capabilities, I developed reports that support informed, data-driven decision-making through effective data storytelling and visualization.

📅 Transforming date fields
🔗 Merging and appending datasets
📂 Handling missing values
